# Decisions log

Record every change from the Master Build Prompt here, with a reason.

| # | Decision | Why | Who / when |
| --- | --- | --- | --- |
| 1 | Precomputed JSON/Parquet/NPZ files in `data/cache/` instead of Zarr on MinIO, PostgreSQL/PostGIS/pgvector, Redis and Celery | 48-hour build; no servers to set up; heavy maps are precomputed anyway | Starter repo, Sat 14 Nov |
| 2 | Per-pixel map trends use **annual means** (years with ≥ 10 valid months), Sen slope + Mann-Kendall, then Benjamini-Hochberg FDR at q = 0.10 | Removes seasons, reduces autocorrelation, keeps 100k-cell maps fast; regional cluster series still get the full monthly pipeline | Starter repo |
| 3 | Pettitt change-point runs on the **residuals from the Sen trend line**, not the raw anomalies | On raw anomalies any steady trend looks like a mid-record "change-point" and would wrongly block grade A | Starter repo |
| 4 | Years-to-significance simulates AR(1) noise, tests annual means with the original MK, 200 sims for live use and 1,000 in `make seed` | Speed; the full plan's 1,000 sims with modified MK per click is too slow | Starter repo |
| 5 | Modified MK falls back to the original variance if the Hamed-Rao factor is ≤ 0 | Rare edge case with strong negative autocorrelation produces an invalid variance | Starter repo |
| 6 | LLM via a plain HTTP call (Anthropic Messages API), model set by `LLM_MODEL` | Fewer dependencies; swap provider by editing `apps/api/app/ai.py` | Starter repo |
| 7 | **CesiumJS replaces MapLibre** for the globe (plain Cesium in `useEffect`, no resium) | True 3D at every zoom (tilt, terrain, atmosphere, lighting) for a realistic globe; `NEXT_PUBLIC_GLOBE_MODE=static` is the fallback | WEB, Sat 14 Nov |
| 8 | Web uses **static JSON fixtures** (`apps/web/fixtures`, generated by `scripts/make-fixtures.mjs`) instead of MSW; one switch `NEXT_PUBLIC_USE_FIXTURES` | Fewer moving parts; fixtures are computed from synthetic series so numbers are internally consistent; clearly labelled SYNTHETIC with an on-screen banner | WEB |
| 9 | Web **Zod schemas follow the running API** where it differs from the written contract: `region.area_km2` optional (not sent yet), `data_quality.gaps` count or list, `evidence_grade.label` accepted, trend map as `grid.lat[]/lon[]` + `[lat][lon]` arrays | Build against what actually runs; API owner can add `area_km2` / `bbox` later without breaking web | WEB |
| 10 | Web reads errors as a top-level problem object **or** FastAPI's `{"detail": {type,title,detail}}` | `HTTPException(detail=dict)` wraps the problem object in `detail` | WEB |
| 11 | Zod is the source of truth for response types; `openapi-typescript` output is advisory only | API endpoints return `dict[str, Any]`, so the OpenAPI doc has no response schemas | WEB |
| 12 | Tailwind CSS 4 design tokens live in `app/globals.css` (`@theme`) instead of `tailwind.config` | Tailwind 4 is CSS-first; there is no config file | WEB |
| 13 | Next.js 16 with **Cache Components** on (scaffold default) | Static shells prerender; client data via TanStack Query; `useSearchParams` components go inside `<Suspense>` | WEB |
| 14 | Globe imagery from NASA GIBS (EPSG:3857, settings checked against WMTSCapabilities.xml): **Blue Marble Shaded Relief + Bathymetry** everywhere, **VIIRS Black Marble** city lights on the night side, **Landsat WELD true colour (2000 annual composite, ~30 m)** below ~450 km | Brief asked for VIIRS true colour at close range, but daily VIIRS (375 m) is blurry at city zoom and was partly cloudy over Kumasi on every date sampled (Nov 2025 to Mar 2026). WELD is sharp and cloud-free; its age (2000) is stated in the on-globe credit. Ocean no-data is keyed out with `colorToAlpha` | WEB, Sat 14 Nov |
| 15 | Fixed sun at 15:00 UTC on the current day (clock not animated) | Ghana always in daylight for the demo, day/night line with city lights visible on the start view; lighting fades out automatically when zoomed in | WEB |
| 16 | Static globe fallback uses a committed GIBS WMS Blue Marble image (`public/images/earth-africa.jpg`); the globe also falls back to it automatically if Cesium/WebGL fails to start | Works offline and on machines without WebGL | WEB |
| 17 | Twi strings (verdict card + Kumasi case only, `apps/web/lib/i18n/tw.json`) are a **draft** | Written without a fluent speaker; must be reviewed before the pitch. API verdict sentences stay in English and are marked `lang="en"` | WEB |
| 18 | `POST /variables/search` response shape is not agreed: web accepts a list of ids/variables or `{results: [...]}` and falls back to keyword matching on catalog `synonyms` on any error | Wizard works with or without the SHOULD endpoint | WEB |
| 19 | Drawn boxes call `POST /trend` with `region_id: null` and `bbox: [w, s, e, n]` (capped 0.25°–10° client-side) | Matches the frozen contract; the current API returns 404 for boxes until it reads `bbox` | WEB |
| 20 | Trend maps, opposite trends and globe clicks use the `west_africa` cached grid for every analysis | It is the only region with cached grids; change `MAP_REGION` in `apps/web/lib/region.ts` when more exist | WEB |
| 21 | Grade labels follow the stats engine (`A` Strong evidence, `B` Moderate evidence, `C` Suggestive only, `D` No significant trend) | Labels come from `evidence_grade.label`; the web defaults match `stats_engine/grade.py` | WEB |
| 22 | Globe demarcations are **vector** borders from Natural Earth 1:10m (public domain): West African countries, Ghana highlighted, Ghana's regions with names (`apps/web/public/geo/boundaries.json`, built by `scripts/build-boundaries.mjs`) | GIBS `Reference_Features`/`Labels` rasters are thin, blur up close and the `_15m` variants returned HTTP 500/empty tiles; vectors stay crisp, can highlight Ghana, and power the hover place names | WEB |
| 23 | Camera flights are focus-locked (`lookAt` every frame) instead of Cesium `flyTo`; areas are framed by their size; the target is offset beside the results panel | Keeps the country/point of interest in view during the whole zoom | WEB |
| 24 | Hover readout on the globe uses the already-loaded trend-map payload (no extra requests): place name, cell value, FDR significance, p | Instant, offline-safe; numbers are the API's own | WEB |
| 25 | Trend layer rendered as a **smooth glowing heatmap** (opacity follows trend strength, bloom glow + blur, feathered edges) instead of crisp grid cells; palette stays colour-blind-safe RdBu/BrBG rather than a rainbow ("jet") scale | Requested heatmap look for the pitch; rainbow palettes are not colour-blind safe (brief). Exact cell values remain available via hover and the legend's table | WEB |
| 26 | Heatmap rendering refined: values are interpolated then coloured (crisp organic contours, no blur or grid squares), visibility is relative to each map's spread (50th→97th percentile of \|trend\|, so intense areas dominate), rounded falloff at the data border, palette restricted to its brighter 10–90% range | From far away the layer looked boxy and blurred; weak changes are now clear rather than tinted (legend says "clear areas changed less", hover gives exact values) | WEB |
| 27 | Visitor location via the browser Geolocation API only (never sent to the API or a third party); landing globe turns to it, /explore flies there when inside the mapped area; `NEXT_PUBLIC_AUTO_LOCATE=0` disables it | Requested "focus on my location"; IP-lookup services would leak the visitor's IP to a third party; disable on the projector to avoid a permission prompt mid-pitch | WEB |
| 28 | Supersedes the close-range part of #14: below ~1,500 km the globe fades to **Sentinel-2 cloudless 2024 (EOX, ~10 m)** instead of Landsat WELD 2000 | WELD looked hazy, seamed and blurry at Kumasi zoom; Sentinel-2 cloudless is sharp, cloud-free and recent. Non-NASA basemap, imagery only (no statistics). Licence CC BY-NC-SA 4.0 (fine for a non-commercial hackathon demo), credited on the globe | WEB, Sat 14 Nov |
| 29 | `.gitattributes` marks `data/raw/**` and `data/cache/**` as `-text`, and pipeline outputs are written with `newline=""` and forward-slash paths | These files are SHA-256 checked by `make seed`; Windows checkouts with `core.autocrlf=true` changed their bytes and broke the checksum, and backslash paths recorded on Windows would not resolve on Linux (CI, Render) | Backend, Sat 14 Nov |
| 30 | Rainfall is reported in **mm/day** (GPM `precipitation` in mm/hr multiplied by 24), not mm/month | NASA metadata gives the unit as mm/hr but does not state that the monthly value is a mean rate over the month, so the mm/month conversion (multiply by hours in the month) would rest on an unverified assumption. mm/day is the same rate in other units. STATS may switch to mm/month once the IMERG documentation confirms the definition | Backend, Sat 14 Nov |
| 31 | West Africa grids come from **Earthdata cloud OPeNDAP server-side subsets** (`pipelines/ingest/opendap_grid.py`); GPM's 0.1° cells are averaged into 0.5° blocks (a block needs at least half its cells valid) | Whole global files would be about 36 GB (CMR sizes) against about 64 MB of subsets; 0.5° keeps the map within seed's 25,000-cell input limit (3,200 cells) and follows the plan's "downsample" advice. MERRA-2 keeps its native 0.5° x 0.625° grid (2,665 cells) | Backend, Sat 14 Nov |
